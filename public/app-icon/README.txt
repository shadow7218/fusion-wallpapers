FUSION - app icon / loading-screen logo folder
==============================================
This folder is ONLY for the logo people see when they install Fusion to the
home screen and open it (the loading / splash screen and the home-screen icon).
The logo inside the website itself (public/logo.webp) is NOT touched by this folder.

To change the loading logo later, replace these files and keep the same names:

  icon-192.png            192 x 192  PNG  (rounded corners with transparent background is fine)
  icon-512.png            512 x 512  PNG  (same artwork, bigger)
  icon-maskable-512.png   512 x 512  PNG  (artwork centred with plenty of space around it;
                                           Android may crop this one into a circle or squircle)
  apple-touch-icon.png    180 x 180  PNG  (iPhone icon, no transparency)

After changing them, people must remove the app from their home screen and
install it again to see the new logo (the phone saves it at install time).

# Fusion Wallpapers

A wallpaper discovery and sharing platform built with
Next.js, React, TypeScript and Supabase.

## Features
- Wallpaper browsing
- Wallpaper sharing
- User profiles
- Authentication
- Responsive UI

## Tech Stack
- Next.js 16
- React 19
- TypeScript
- Supabase
- Tailwind CSS
